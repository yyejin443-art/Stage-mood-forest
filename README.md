# STAGE:MOOD — Forest

An interactive theatrical forest-stage designer built with Streamlit.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Controls
- Time of day: dawn, day, sunset, night
- Light entering between the trees
- Tree density on stage
- Forest fog / atmosphere
- Forest arrangement variation

## Project concept
The same forest set can communicate different moods depending on the time of day and the amount of light passing through the trees.
